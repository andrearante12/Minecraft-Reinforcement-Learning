World models

Malmo observations are already compact state vectors, and every step is a 0.15s hold. That makes a Dreamer-style world model cheap — and valuable, because imagined steps replace expensive real ones.

The showcase task is hunting

The observation is 98 numbers: body, a moving target (relative pose, heading error, line-of-sight, life), and a 5×3×5 voxel patch. Eleven discrete actions including attack.

A single point-prediction of where the pig will go, trusted equally at every imagined step, is the failure mode. We train an ensemble of probabilistic models so the agent can measure its own uncertainty and split it.

Loop

Collect real transitions → fit the ensemble → imagine H steps from real starts → update the same three-stream actor-critic in imagination. Policy checkpoints stay byte-compatible with PPO / DQN / BC; the world model rides along as extra state.

Mechanisms are implemented and offline-validated (ensemble NLL, epistemic shrinks on refit, gating truncates the horizon). Live Malmo comparisons vs PPO/DQN are still the study, not a claimed result.

Pixels, separately

A second architecture — DreamerV1-style RSSM on 64×64 frames plus the same 98-d vector — exists so the project also speaks the robotics-from-pixels dialect. No ensemble in v1. Not checkpoint-compatible with the vector agent.
